# 方法选择题规范 v1

## 设计大纲

组合来自至少两篇论文的 3–5 道来源题。每道来源题必须在方法空间、证据、评价
指标或设计变量中承担可追溯的实质作用。必须构造共同的科学对象和基准，禁止仅因
单位一致就拼接不相容的论文数据。

`QuestionDesignBrief` 至少保留两个合理方法选择，说明公开证据为什么足以区分
它们，定义隐藏评价轴，并解释诚实解为什么存在。预计正常解题耗时不得超过
1800 秒。

## 题目设计

难度应来自表示、诊断、迁移、权衡或方法设计，而不是冗长计算和环境安装。标题和
题面不得暗示胜出方法。公开训练证据应覆盖相关机制但不泄漏隐藏部署样例；隐藏
样例必须位于公开声明的范围内，并通过存在性、唯一性和稳定性检查。

每个评分量都必须有来源账本、独立交叉检查和可解释容差。Verifier 应奖励科学预测
和决策质量，格式与报告合规不得主导分数。

## 难度验证

Oracle 和对抗检查通过后，对同一冻结题包执行三轮全新盲解。新题默认由 Harbor
沙盒中的 Codex + `matmaster/gpt-5.6-sol` 执行。盲解分数达到或超过 0.85 时判定
为 `TOO_EASY`。盲解失败只能获得已公开的总分和分项分数。

三轮有效科学盲解均未通过后，才能加入经过独立审核且不包含答案的提示。完成题目
需要带提示解题通过，或满足经过审计的能力边界，并且所有健康门仍然有效。平台、
环境、harness 和模型连接失败不计为科学尝试；科学执行达到 3600 秒后暂存该题。
