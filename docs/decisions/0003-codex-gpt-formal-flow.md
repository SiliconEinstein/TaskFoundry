# ADR 0003：Codex + GPT 正式出题流程与自动编排边界

状态：2026-08-24 已确认并实现；并发决定由 ADR 0004 更新。

## 问题与非目标

TaskFoundry 已能记录单题状态、冻结题包并审计 Harbor 回执，但仍需要人工逐步
调用脚本。正式出题还会受到临时 harness 对比实验影响，Labwright 请求也只是
落盘而没有形成可恢复的服务闭环。

本次改造不把 harness 对比实验纳入正常出题流程，也不允许当前 Teacher 会话
直接充当 Researcher 解题。历史实验数据保留为证据，但不再作为新题编排接口的
一部分。

## 模式与范围

- Engineer Large Code：STRICT / L3，INCREMENTAL。
- 临时架构层：领域契约、应用编排、外部适配器、命令行。
- 每个实现切片不超过 300 行有效生产代码、6 个生产文件和 2 个架构层。
- 新增或修改的代码注释、公开契约说明和项目文档使用中文。

## 已冻结的决策

1. 正常出题只存在正式验证通道，不设计对比实验通道。
2. 新题默认使用 Harbor 沙盒中的 Codex harness 和 `matmaster/gpt-5.6-sol`。
3. Teacher 只能签发 Researcher 请求；解题必须由独立 Researcher 在 Harbor
   沙盒中执行，不能由当前 Teacher 会话直接完成。
4. 题目设计目标是正常 Researcher 预计 1800 秒内完成；正式 Agent 硬超时为
   3600 秒。达到硬超时后暂存该题并调度下一题。
5. DSH 仅为历史兼容能力，不是新题默认路径。是否再次启用为默认值必须有新的
   独立验证证据。
6. 最多同时推进 3 道题的旧决定已由 ADR 0004 取代。

## 建议流程

1. 题型模块生成并验证 `QuestionDesignBrief`，其中明确 1800 秒目标耗时。
2. Teacher 锁定规范并提出环境能力，不直接执行环境命令。
3. Labwright 解析稳定镜像；缺失能力时创建可恢复的增量请求。增量完成后重新
   生成稳定镜像回执。
4. Teacher 生成题包。Oracle、诚实解、对抗和泄漏证据必须绑定当前题包、环境
   和修订摘要。
5. Teacher 签发 Codex + GPT Researcher 请求。Researcher 在 Harbor 沙盒执行，
   返回不可修改的原始回执；Reviewer 生成派生审计记录。
6. 三轮盲解和后续提示验证只消费正式回执。平台、环境、harness 和模型连接
   失败不计科学尝试。
7. 调度器根据持久状态自动继续、暂存或补充下一题。

## 公开契约变化

- `QuestionDesignBrief` 增加目标解题时间，默认且最大为 1800 秒。
- `ResearcherRequest` 的默认 harness/model 改为 Codex + GPT，并继续固定
  3600 秒科学执行上限。
- 新增持久调度条目和调度快照；它们只管理正式出题，不接受实验用途。
- Labwright 增量请求增加状态回执和恢复信息，避免调用者理解底层镜像步骤。

## 兼容和迁移

旧的 DSH 请求和历史运行记录保持可读取。新增字段使用兼容默认值；旧记录不被
重写。Q17 的历史对比实验继续保存在原目录，但新调度器不会导入这些实验尝试。

## 并发、安全和恢复

- 调度状态更新使用文件锁、序列号和原子替换；并发上限见 ADR 0004。
- 每个外部操作具有幂等键。陈旧租约可恢复，但不得复制正式科学尝试。
- Researcher 请求继续绑定题包、JobConfig、角色任务和一次性 capability。
- 凭证只以环境变量名出现；日志和持久状态不得保存凭证值。

## 错误边界

失败阶段区分为环境、沙盒、harness 启动、模型连接、科学执行、Verifier 和平台。
只有已经进入科学执行且得到权威 reward 的结果进入难度统计。3600 秒科学超时
触发题目暂存，不等同于题目失败。

## 实现切片

1. 领域契约与调度存储：模型、持久队列、状态决策和单元测试。
2. 正式运行配置：Codex + GPT 默认值、预检、失败阶段和回执审计。
3. Labwright 闭环：增量状态、稳定镜像发布回执和修订失效规则。
4. CLI 与集成：自动补位、恢复、完整单题演练和中文运行文档。

## 验证

- 单元测试覆盖调度上限、自动补位、租约恢复、30/60 分钟约束和失败分类。
- 集成测试覆盖一题暂存后下一题自动进入活动状态。
- 运行结构检查、完整 pytest、公开契约消费者检索和至少一条无外部副作用的
  端到端演练。

## 回滚边界

代码可回滚到 ADR 0002。新增调度和证据文件只追加或由新版本忽略，不删除旧
运行证据，不撤销已经发布的镜像，不重复已有 Harbor 尝试。

## 豁免与未决项

当前没有豁免，也没有阻塞实现的未决项。
